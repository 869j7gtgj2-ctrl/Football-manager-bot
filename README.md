# ⚽ Football Manager Bot

Телеграм-гра: футбольний менеджер. Ти головний тренер і менеджер клубу: склад, тактика, трансфери, фінанси, академія. Усі клуби й гравці вигадані.

## Що є в грі

- **Дві ліги** по 12 клубів (Прем’єр-ліга і Перша ліга), двоколовий турнір на 22 тури, по 2 клуби підвищуються і вибувають.
- **Рушій матчу хвилина за хвилиною**: моменти з різною якістю (xG), голи й асисти, жовті й червоні картки, травми, заміни через втому, оцінки гравців, гравець матчу. Live-трансляція в чаті або швидкий результат.
- **Тактика**: 7 схем (4-4-2, 4-3-3, 4-2-3-1, 3-5-2, 5-3-2, 4-5-1, 3-4-3) і 5 стилів (атака, баланс, оборона, контратаки, пресинг) зі своїми плюсами й мінусами.
- **Гравці**: майстерність, потенціал, вік, фізична форма, настрій, контракт, зарплата, вартість. Молоді ростуть, ветерани старіють і завершують кар’єру.
- **Тренування**: фокус на атаці, обороні, фізпідготовці чи молоді. Рівень тренувальної бази впливає на прогрес.
- **Трансфери**: ринок за позиціями, вільні агенти, молоді таланти. Трансферні вікна (початок і середина сезону). Ставки від інших клубів на твоїх гравців, швидкий продаж, розірвання і продовження контрактів. Гравці можуть відмовити «неамбітному» клубу.
- **Економіка**: квитки (ціну ставиш сам), спонсори, призові, зарплати. Розширення стадіону, тренувальна база, академія.
- **Академія**: щосезону нові вихованці, кращі при вищому рівні академії.
- **Правління**: ціль на сезон і рівень довіри. Провалиш — звільнять.
- **Зала слави**: рейтинг найкращих тренерів серед усіх гравців бота.

## Запуск локально

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
export BOT_TOKEN=...   # токен від @BotFather
python main.py
```

Тести: `pytest -q`

## Деплой на Railway

1. New Project → Deploy from GitHub repo → обрати цей репозиторій.
2. Variables: додати `BOT_TOKEN` (токен від @BotFather) і `DATABASE_PATH=/data/kickoff.db`.
3. Додати Volume з точкою монтування `/data`, щоб прогрес гравців не зникав після перезапуску.
4. Railway сам збере `Dockerfile` і запустить бота.

## Деплой на Render

Background Worker → цей репозиторій → Docker. Змінні ті самі. Для збереження даних підключіть Persistent Disk на `/data`.

## Структура

- `kickoff/game/` — рушій гри без залежності від Telegram (моделі, генерація світу, матч, сезон, трансфери)
- `kickoff/bot/` — інтерфейс Telegram (aiogram 3)
- `kickoff/storage.py` — SQLite: кожна кар’єра зберігається як стиснутий JSON
- `tests/` — тести рушія і прохід по всіх екранах бота
