# ⚽ Football Manager Bot

Телеграм-гра: футбольний менеджер. Ти головний тренер і менеджер клубу: склад, тактика, трансфери, фінанси, академія. Усі клуби й гравці вигадані.

## Що є в грі

- **Telegram Mini App** з яскравим інтерфейсом: профіль тренера з рангом і досвідом, монети, щоденний бонус і серія, завдання й досягнення, магазин, 3 слоти кар’єр.
- **Справжні ліги сезону 2026/27**: УПЛ, Перша ліга, АПЛ, Ла Ліга, Бундесліга, Серія А, Ліга 1. Сила клубів відповідає реальному рівню. Між УПЛ і Першою лігою працюють підвищення і пониження.
- **Справжні гравці й емблеми**: сервер сам завантажує поточні склади, вік, національність і емблеми з Вікіпедії/Wikidata, а для топ-5 ліг ще й з football-data.org (якщо задано ключ). Оновлення раз на тиждень. Вихованці академії генеруються з іменами за національністю.
- **Матч наживо**: хвилина за хвилиною, голи, сейви, картки, травми, заміни, xG, оцінки, гравець матчу, конфеті за перемогу.
- **Тактика, тренування, академія, трансфери з вікнами, ставки клубів, фінанси, стадіон, правління.**

## Запуск локально

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
export BOT_TOKEN=...   # токен від @BotFather
python main.py
```

Тести: `pytest -q`

## Деплой на Railway

1. New Project → Deploy from GitHub repo → обрати цей репозиторій.
2. Variables: `BOT_TOKEN` (токен від @BotFather), `DATABASE_PATH=/data/kickoff.db`, за бажанням `FOOTBALL_DATA_KEY` (безкоштовний ключ з football-data.org).
3. Volume з точкою монтування `/data`, щоб прогрес не зникав після перезапуску.
4. Settings → Networking → **Generate Domain** (порт 8080). Бот сам поставить кнопку меню «Грати» з цим доменом (Railway передає його в `RAILWAY_PUBLIC_DOMAIN`).

## Деплой на Render

Background Worker → цей репозиторій → Docker. Змінні ті самі. Для збереження даних підключіть Persistent Disk на `/data`.

## Структура

- `kickoff/game/` — рушій гри без залежності від Telegram (моделі, генерація світу, матч, сезон, трансфери)
- `kickoff/bot/` — інтерфейс Telegram (aiogram 3)
- `kickoff/storage.py` — SQLite: кожна кар’єра зберігається як стиснутий JSON
- `tests/` — тести рушія і прохід по всіх екранах бота
